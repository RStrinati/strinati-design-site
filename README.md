# STRINATI Design Website

Static website for **strinatidesign.com**.

## Hosting

Designed for Cloudflare Pages with GitHub-based automatic deployment.

- Production branch: `main`
- Build command: none
- Build output directory: `/`

## Site structure

- `/` — STRINATI Design home
- `/work/` — portfolio / selected work
- `/dental/` — dental feasibility overview
- `/dental/uk/` — UK dental feasibility
- `/dental/au/` — Australia dental feasibility
- `/posters/` — poster collection
- `/digital/` — digital / BIM app
- `/about/` — about
- `/contact/` — contact

## Domains

- `strinatidesign.com` — primary STRINATI Design website
- `sd-app.com` — separate BIM / digital product domain

## Deployment

Connect this repository to Cloudflare Pages and use `main` as the production branch. No framework or build step is required.
